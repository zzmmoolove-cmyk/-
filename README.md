# 紫微斗数 · AI 查盘

基于开源排盘引擎 [iztro](https://github.com/SylarLong/iztro)（MIT）与 [react-iztro](https://github.com/SylarLong/react-iztro)（MIT）构建的紫微斗数排盘 / 查盘工具，并叠加自建的「知识库优先、AI 兜底」解读层。

## 功能

- **排盘**：公历 / 农历出生信息 → iztro 确定性排盘（十二宫、主星、辅星、四化、大限、神煞）。
- **出生地一次带入**：内置 356 个城市的经纬度；城市选择一次同时供真太阳时（经度）与上升星座（纬度），不需要用户再填一遍纬度。真太阳时开关只决定是否校正时刻。
- **宽松日期/时间输入**：日期支持 `19980527`、`1998-05-27`、`1998年5月27日`；时间支持 `0930`、`9:30`、`9点30`、`下午3点`、`9:30 PM`，统一转 24 小时制。
- **盘面层级全覆盖**：本命 / 大限 / 小限 / 流年 / 流月 / 流日 / 流时，一键切换，运限流耀与四化叠加展示，小限宫位高亮。
- **排盘流派**：三合（默认）/ 中州派安星算法，以及年份/大限/岁数/流日分界选项。
- **三方四正 / 夹宫 / 四化飞星**：点宫位查看对宫、三合、夹宫及四化飞入飞出。
- **星曜档案库（67 颗 + 50 颗运限派生）**：点击盘面 / 宫位卡上的任意星曜，弹出「五行根性 → 核心象义 → 正负面 → 四化自化 → 十二宫投射 → 组合提示 → 用星建议」；**67 颗全部有逐宫短句**（含咸池、天喜等乙级星与杂曜），运昌/流禄等运限流曜按「本命星 × 层位」派生说明，不伪装成独立星曜；支持导出 JSON 备份。
- **盘面批注层**：悬停盘上的星曜、庙旺字、四化字、宫名、长生十二神、博士/岁前/将前十二神、宫干支、大限小限，出现一句话批注；点击打开星曜档案或概念说明（宫干支弹层附「本宫宫干四化 → 目标宫」）。
- **宫位卡 1.0**：任意宫位一键生成结构化报告（宫位定位 / 本宫星曜 / 同宫联动 / 三方四正 / 五行链 / 四化 / 卡点与动作 / 用星建议 / 数据缺口），并附「复盘自检」。
- **复制 Prompt 喂给通用大模型**：宫位卡内置「结构说明 + 本宫数据 + 输出格式 + 质量红线」，一键复制，不依赖 API Key。
- **宫位快速切换**：盘面直接点宫位；打开「详」后右上出现宫位下拉。不再额外维护一张十二宫索引。
- **命盘可视化**：react-iztro 渲染本命盘；直接点盘面宫位查看右侧检查器，不再额外堆一张十二宫卡片列表。
- **宫位解读（第 1 层，0 成本）**：检索知识库（14 主星 + 12 宫位 + 六吉六煞等），即时组装解读。
- **命格综述（第 2 层，0 成本）**：自动判定经典格局（紫府同宫、君臣庆会、七杀朝斗、杀破狼等）、汇总四化飞星，生成整盘综述。
- **AI 兜底（第 3 层）**：填写自己的 API Key（DeepSeek / OpenAI / 通义千问 / 自定义），对整盘或单个宫位进行 AI 综合解读。Key 仅存本机 localStorage。
- **安星码**：一键复制 / 导入排盘配置，可分享复现同一命盘。
- **命盘上方直选时间**：大限 / 流年 / 流月 / 流日按行排列，像筛选一样直接点；时间条吸顶贴合命盘，不折叠；选到哪一级，下面显示对应命盘与报告。
- **宫位点选整合**：点盘面宫位 → 盘上画三方四正虚线 + 右侧当前宫位检查器；本限加权、流曜、四化、三方四正、卡点都在同一张检查器里。打开「详」时，命盘右上出现宫位下拉点选。原来单独的十二宫卡片列表已移除。右上角小按钮「宫位卡 ↗」展开完整卡，带加权拆解；加权 = 本命 50% + 大限 20% + 流年 15% + 流月 10% + 流日 5%，按已选层归一化。
- **运限报告**：大限版 / 流年版 / 流月版 / 流日版；流日版同时带万年历（公历/农历/干支/宜忌/冲煞）与当天建议，可打印/另存 PDF。
- **今日 · 万年历流日**：主客户下方侧栏直接显示今日日期/农历与紫微、八字、星座三行摘要；点「展开今日 · 万年历」进完整流日、黄历宜忌/冲煞与日期切换。
- **用户档案**：姓名 + 关系（本人/父母/配偶/子女/客户等）+ 出生信息 + 备注，保存 / 切换 / 删除；旧版排盘记录自动迁移。
- **客户工作台**：Sidebar **命主（默认首页）** / 服务 / 资料；主客户卡片下方直接展示今日摘要；命主页集中客户列表、主客户开关、排盘入口；顶栏当前客户/主客户；解盘内「范围（本命/大限/流年/流月/流日）+ 视图（命盘/宫位卡/综述/运限报告）」；右侧宫位检查器。
- **资料 / 设置分布**：资料只保留星曜手册 + 古籍，数据在资料页右上角；万年历移入「今日」，与主客户流日运势合并；排盘设置、AI 设置、数据全部收进网页右上角「设置」。
- **设置入口**：顶栏右上角，含排盘设置 / AI 设置 / 数据三个页签；不再占用资料页。
- **主客户开关**：命主页每个人一个开关，打开谁谁就是主客户；主客户是今日流日、三系统首页与服务记录的默认基准，独立于当前打开的解盘客户。开关只切主客户，不删盘、不切当前命盘；点「排盘 →」才进入命盘页面。选择会记住。
- **命主筛选**：全部 / 家人 / 朋友 / 同事 / 客户 / 名人 / 其他；集中在命主页，不再挤在侧栏。
- **名人示例**：内置 10 位名人示例盘（李小龙、张国荣、梅艳芳、邓丽君、周杰伦、王菲、刘德华、林青霞、马云、姚明）。生时未公开，统一按午时 12:00 占位，仅用于筛选与查盘演示，不作真实命例。
- **今日 / 客户档案**：继续解盘、解盘记录、服务记录；命主列表 / 档案 Sheet / 新建命主 Sheet。
- **输出设置 + PDF**：导出前勾选章节（含古籍摘录）、参考书目标注、排盘流派；设置记在本机，下次直接沿用；用浏览器打印生成 PDF（自动展开报告折叠区）。
- **服务**：起名 / 择日 / 合盘 / 投资 + **服务记录流**；生成后可保存、标记交付、复制全文、导出单条服务 PDF；合盘记录同时归到 A/B 两位客户。合盘 B 可在服务页就地新建，只建档案、不切换当前 A 盘。团队测评保留路线入口。
- **运限报告**：大限 → 流年 → 流月 → 流日逐级叠加；每层显示运限命宫落本命宫位、四化落宫、重点宫位流曜，可一键复制。
- **服务 · 起名参考**：先选出生日，比较当天 12 时辰的命盘结构分并推荐，按选中时辰的四柱五行挑字、配声调与笔画；输出 5 个候选名和理由。命宫星曜附古籍摘录（整理本），但字义/音律/笔画来自字库与规则，不冒充古籍原文。
- **服务 · 择日参考**：按事项关键词、黄历宜忌、生肖冲煞与周末权重，对未来 30/60/90 天排序；输出首选日 + 备选日 + 理由。
- **服务 · 投资倾向**：以财帛宫、福德宫、命宫定「财富剧本」，做守成力 / 进攻性 / 纪律性 / 正财力四维自检，再叠当前大限/流年节奏；明确不预测指数、个股与收益率，不构成投资建议。
- **服务 · 八字详盘**：四柱、藏干、十神/副星、十二长生（星运）、自坐、空亡、纳音、神煞、胎元/命宫/身宫，并用扶抑初判给用神方向；数据来自 lunar-typescript，页面保留“非完整师承”提示。
- **今日 · 三系统**：同一日期同时给紫微流日、八字日柱/十神、星座太阳过境；先看三张今日卡，再看具体建议。
- **服务 · 双人合盘 v3**：紫微 / 星座 / 八字三个板块 + 综合参考分。**紫微五维加权（核心 24 / 情感 22 / 精神 18 / 沟通 17 / 五行 19），只读命宫/夫妻/福德，不读取太阳星座**；关系类型也改为同星/托举/同气/滋养/主导/压节奏等紫微结构，不再出现「风象同频」这类星座类型。星座独立补太阳/上升/下降、元素、相位；八字补四柱、日主、夫妻宫、合冲害与五行互补。三系统综合 = 紫微 45% + 星座 30% + 八字 25%，并给出「如果只记三句话」的关系建议。
- **团队 / 性格测评**：已在服务区留入口与路线（团队角色模型、一页纸报告），下一版接入。
- **玄夜 / 宣纸双主题**：默认「玄夜」深空暗色——星图、鎏金、宋体标题、玻璃面板、四化小印与悬停微光；一键切回「宣纸」浅色，选择记忆在本机。
- **三方四正虚线**：悬停宫位实时重绘对宫 + 两个三合宫的金色虚线，离开盘面回落到当前选中宫。

## 从命盘到交付物

- **起名**：一个名字 + 5 个候选 + 五行/音律/字义理由。
- **择日**：一个首选日 + 备选日 + 宜忌/冲煞/周末理由。
- **合盘**：双人关系结构报告 + 可下载分享卡。
- **投资**：个人财富剧本、四维风险自检、大限/流年节奏；不预测指数/个股，不构成投资建议。
- **团队**：命盘 → 沟通风格/团队角色报告（路线中）。

这些模块不改变排盘引擎，只在既有命盘之上加规则、模板和交付物；更适合按次收费或打包成服务。

## 快速开始

```bash
npm install        # 若提示 npm 缓存 EPERM，可加 export npm_config_cache="$(pwd)/.npmcache"
npm run dev        # 打开 http://localhost:5173/
npm run build      # 生产构建到 dist/
```

## 宫位卡 1.0

结构说明与产品参考见 [`docs/宫位卡-1.0-结构.md`](docs/宫位卡-1.0-结构.md)：

- 分层：排盘引擎（iztro）→ 星曜档案库 → 规则引擎 → 宫位卡 → Prompt / AI
- 权重：本宫 1.0 ＞ 对宫 0.6 ＞ 三合 0.45；吉煞比 =（吉−煞）/（吉+煞）
- 卡点规则 v1.0：空宫、无主星、煞星入宫、主星落陷、吉星落陷、自化忌、生年忌、禄忌同宫、对宫冲照
- 每条卡点固定「依据 → 影响 → 解法 → 动作」，缺数据显式标注，不硬编
